# NQ Backtest Lab — مختبر الباك-تست المجاني

> **الغرض**: تمكين تحقّق مستقل من أي استراتيجية تداول **بتكلفة صفر** — بلا مفتاح API، بلا حساب، بلا اشتراك.
> **الحالة**: نسخة v4 بعد إصلاح ثغرتَي انتقاء كشفهما مراجع مستقل.

---

## ما هذا؟

مختبر باك-تست كامل يعمل ببيانات سوق عامة، ويطبّق **نفس دستور الباك-تست** المستخدم في مشروع NQ:

| البوابة | الشرط |
|---|---|
| حجم العيّنة | <30 فكرة · <100 مؤشر · <400 غير موثوق · ≥400 يُعتمد |
| الفترة المغلقة | PF خارج العينة ≥ 1.3 |
| الإجهاد | يصمد بعد حذف أفضل 3 صفقات |
| التراجع | يُقاس بوحدة R (المقياس العادل عبر أسواق مختلفة الأحجام) |
| التقسيم | تاريخ قطع واحد، قواعد مجمّدة ومهشّرة (`rules_hash`) |

المحرّك ينسخ قواعد `nq100_portfolio/trend_universe.py` حرفياً:
EMA200 · MACD(12,26,9) · ATR(14) · وقف 1.5×ATR · متحرك 3.0×ATR · مخاطرة 0.8% · تكاتر 0.055% + انزلاق 0.01% · تنفيذ على افتتاح الشمعة التالية (بلا تسريب مستقبلي).

## الاستنتاج المركزي

> **الميزة في نوع الأصل، لا في عدد الأسواق.**

1. **الفوركس خاسر صريح** في هذا النظام: −0.360R على 105 صفقات (−42% تراجع).
2. **توسيع الكريبتو يقتل الميزة**: 6 عملات PF 1.24 ← 22 عملة PF 0.95.
3. **داخل الكريبتو، الميزة محصورة في أكبر 5** (+0.191R)؛ الرتب 6-12 سالبة (−0.158R).
4. **المؤشرات والسلع أقوى من الكريبتو** (+0.269R و +0.370R).

**الحدّ الصريح**: أفضل تعريف (R6 + C12) يحقق **3/4 بوابات** وعيّنته 303 صفقة — **تحت شرط 400**. لا شيء هنا جاهز لمال حقيقي.

## حدود معروفة

1. تكلفة الكلاسيكي نسبة ثابتة (3% من R) — لا سبريد أداة بأداة.
2. Yahoo كريبتو = سعر فوري، بلا تمويل ولا رافعة (Binance Vision = عقود دائمة).
3. لا تنفيذ حي — أي رقم هنا لا يثبت أن التنفيذ يطابق الباك-تست.
4. `R6+C12` يستخدم رموز المستودع الستة (لم أختَرها) — وهو التعريف الأكثر استقلالاً.
5. لم يُتحقّق من قبول أي شركة تمويل لمقيم تونسي.
